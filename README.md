# 🛒 React Challenge - Shopping Cart

Este proyecto es una simulación de un carrito de compras desarrollado con **React** y **Vite** para el frontend. Los estilos están construidos con **TailwindCSS**, y los datos utilizados están mockeados utilizando **JSON Server** como dependencia de desarrollo.

## 🚀 Tecnologías utilizadas

- ⚛️ React + Vite
- 💨 TailwindCSS
- 🗃️ JSON Server (mock)
- 📦 Local Storage

---

## 🎯 Funcionalidades destacadas

- Inicio de sesión con distinción entre usuarios VIP y no VIP.
- Carrito de compras con:
  - Agregado y eliminación de productos.
  - Cálculo de total con descuentos (VIP y promociones por cantidad).
- Aplicación de descuentos condicionales:
  - Descuento del 25% para compras de 4 productos o más.
  - Beneficios adicionales para usuarios VIP.
- Simulación de fecha promocional (editable en el mock).

## 🧪 ¿Cómo probar el proyecto?

### 1. Clonar el repositorio

```bash
git clone https://github.com/LuciaRivero/factor-challenge.git
```

### 2. Movete a la carpeta clonada

```bash
cd factor-challenge
```
### 3. Instalá las dependencias

```bash
npm install

```
### 4. Iniciar el proyecto

```bash
npm run start

```
